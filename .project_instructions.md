# BorsaBi Trader - Project Instructions

## Overview
Turkish trading simulation/education platform (BIST + Crypto). Not real trading - educational/simulation only. Disclaimer: "yatırım tavsiyesi değildir". App name: "BorsaBi Trader". Branding: "Borsa" in foreground color + "Bi" in #3B82F6 blue.

## Logo
- Custom SVG logo at `/public/favicon.svg` and React component at `/components/logo.tsx`
- Exports: `BorsaBiLogo` (icon only), `BorsaBiLogoFull` (icon + text with "Trader" subtitle)
- Design: Blue-purple gradient rounded rect background, green uptrend chart line with arrow, "Bi" text

## Tech Stack
- App Router, Prisma + PostgreSQL, NextAuth, TailwindCSS, Framer Motion
- Yahoo Finance (via `@/lib/yahoo-finance`) + Midas API for BIST data
- LLM API for AI assistant

## Visual Style - iOS Liquid Glass Theme (Light/Dark)
- **Theme toggle**: Sidebar bottom + mobile header. Uses `next-themes` with `defaultTheme="dark"`, stored in localStorage
- **Body background**: 
  - Dark: `linear-gradient(160deg, #0B1120, #0F172A, #111D35, #0B1120)`
  - Light: `linear-gradient(145deg, #f0f4f8, #e8eef6, #f2f5fa, #eaf0f8, #f0f4f8)` - soft blue-white
- **Glass utility classes** (premium frosted style, defined in globals.css):
  - `.glass-card` - Light: white/70 bg, white/85 border, soft shadow. Dark: white/2.5 bg, white/5 border
  - `.glass-sidebar` - Light: white/78 bg, subtle right shadow. Dark: 0b1120/65
  - `.glass-inner` - Light: black/2 bg (inset feel), black/4 border. Dark: white/1.5
  - `.glass-nav` - Light: white/72 bg, soft bottom shadow. Dark: 0b1120/60
  - Light mode uses white borders on cards for soft frosted edges, dark borders on inner elements
  - `.glass-btn`, `.glass-hover`, `.glass-active`, `.glass-divider`
  - Avoid `bg-slate-100 dark:bg-[#0F172A]` - use `glass-inner` instead for theme consistency
- **Text colors**: Use Tailwind CSS variable classes
  - `text-foreground` (was text-white) - auto switches light/dark
  - `text-muted-foreground` (was text-[#94A3B8]) - auto switches
  - Accent colors (#3B82F6, #22C55E, #EF4444, #F59E0B) stay same in both themes
- **Border pattern**: `border-black/[0.06] dark:border-white/[0.06]` for separators
- **Hover pattern**: `hover:bg-black/[0.04] dark:hover:bg-white/[0.04]`

## Candlestick Pattern Detection
- Library: `lib/candle-patterns.ts` — 16 Turkish-named patterns (Çekiç, Boğa Yutan, Sabah Yıldızı, etc.)
- Integrated into ALL scan APIs (screening, day-trading, swing-trading, algo-scan)
- Shown as colored badges in client UIs; score (-10 to +10) added to formasyonPuan

## Tier System (2 tiers only)
- **Free**: 5 alarms, basic screening, 3 backtest/day, standard indicators
- **Pro**: 50 alarms, algo scanning, unlimited backtest, strategy builder, advanced indicators, priority AI, API access, custom strategies
- DB `tier` field: 'free' or 'pro' (legacy 'elite' → treated as 'pro' in UI)

## Key Technical Notes
- Prisma import: `import { prisma } from '@/lib/db'` (named export)
- Yahoo Finance: `import { yf } from '@/lib/yahoo-finance'`
- TradeModal uses `marketType` prop, NOT `yahooSymbol`
- Index symbols (XU100.IS, XU030.IS) skip Midas, use Yahoo Finance directly

- 20+ pages: dashboard, piyasalar, kesfet, portfolio, day-trading, swing-trading, ai-assistant, screening, risk-center, trade-log, watchlist, academy, backtest, algo-scan, strategy-builder, leaderboard, alerts, achievements, aksam-analizi, profile
- Global search bar (⌘K) in top header across all pages - searches BIST + Crypto, navigates to /stock/[symbol]
