# Master Trader - AI Trading Simülasyon Platformu

## Proje Özeti
Türkiye odaklı yapay zeka destekli trading simülasyon platformu. BIST ve kripto piyasalarını destekler. Eğitim ve simülasyon amaçlıdır - gerçek para işlemi yapılmaz.

## Teknik Yapı
- **Framework:** Next.js 14 + React 18
- **Database:** PostgreSQL (Prisma ORM)
- **Auth:** NextAuth.js v4 (email/password)
- **AI:** Abacus AI API (gpt-5.4-mini, streaming)
- **Market Data:** Yahoo Finance API (yahoo-finance2 v3 - instantiated)
- **Styling:** Tailwind CSS, Framer Motion
- **Charts:** Recharts (dynamic import, SSR disabled)

## Sayfa Yapısı
1. `/login` - Giriş sayfası
2. `/signup` - Kayıt sayfası
3. `/dashboard` - Ana dashboard (piyasa özeti, portföy, endeksler, hisseler, kripto)
4. `/portfolio` - Portföy yönetimi (açık/kapalı pozisyonlar, bakiye)
5. `/ai-assistant` - Master AI (streaming chat, Türkçe teknik analiz)
6. `/screening` - Hisse tarama motoru (RSI, MACD, EMA puanlama)
7. `/trade-log` - İşlem günlüğü (işlem geçmişi, istatistikler)
8. `/watchlist` - İzleme listesi (favori hisseler, fiyat takibi)

## API Rotaları
- `/api/market` - Piyasa verileri (Yahoo Finance)
- `/api/market/history` - Geçmiş fiyat verileri
- `/api/portfolio` - Portföy durumu
- `/api/trade` - Alış/satış işlemleri
- `/api/transactions` - İşlem geçmişi
- `/api/watchlist` - İzleme listesi CRUD
- `/api/ai-chat` - AI asistan (streaming)
- `/api/signup` - Kayıt
- `/api/auth/login` - Giriş
- `/api/auth/[...nextauth]` - NextAuth

## Önemli Kurallar
- Tüm içerik Türkçe
- Her AI yanıtında "yatırım tavsiyesi değildir" uyarısı
- Yahoo Finance v3: `new YahooFinance()` ile instantiate edilmeli (`lib/yahoo-finance.ts`)
- Komisyon: %0.2 alış, %0.2 satış
- Risk limitleri: İşlem başına max %1, günlük max %3 zarar
- Sanal bakiye: 100.000 TL başlangıç

## Database Modeli
- User (balance, initialBalance, role)
- Position (symbol, quantity, entryPrice, stopLoss, takeProfit, pnl)
- Transaction (işlem geçmişi)
- Watchlist (izleme listesi)
- ChatMessage (AI sohbet geçmişi)
