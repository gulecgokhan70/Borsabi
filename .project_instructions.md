# Master Trader - AI Trading Simülasyon Platformu

## Proje Özeti
Türkiye odaklı yapay zeka destekli trading simülasyon platformu. BIST ve kripto piyasalarını destekler. Eğitim ve simülasyon amaçlıdır - gerçek para işlemi yapılmaz.

## Teknik Yapı
- **Framework:** Next.js 14 + React 18
- **Database:** PostgreSQL (Prisma ORM)
- **Auth:** NextAuth.js v4 (email/password)
- **AI:** Abacus AI API (gpt-5.4-mini, streaming)
- **Market Data:** Yahoo Finance API (yahoo-finance2 v3 - instantiated)
- **Styling:** Tailwind CSS, Framer Motion
- **Charts:** Recharts (dynamic import, SSR disabled)

## BIST Varlık Veritabanı
- **`lib/bist-data.ts`** (~47KB): Tüm BIST varlıkları
  - `BIST_ALL_STOCKS`: 611 hisse (symbol, name, shortName)
  - `BIST_TOP_STOCKS`: ~98 en likit hisse (tarama API'leri için)
  - `BIST_FUNDS`: 30 BYF/ETF fon
  - `BIST_ALL_ASSETS`: Hisse + Fon birleşimi
- **`lib/constants.ts`**: bist-data.ts'den re-export, backward compat (`BIST_STOCKS = BIST_ALL_STOCKS`)
- **`components/symbol-search.tsx`**: Aranabilir dropdown, gruplu sonuçlar (BIST/Fonlar/Kripto)
- **Tarama API'leri** (`screening`, `day-trading`, `swing-trading`, `algo-scan`): Timeout'u önlemek için `BIST_TOP_STOCKS` kullanır
- **Seçim UI'ları** (backtest, alerts, strategy-builder): Tüm varlıkları gösterir (`BIST_ALL_ASSETS`)

## Önemli Kurallar
- Tüm içerik Türkçe
- Her AI yanıtında "yatırım tavsiyesi değildir" uyarısı
- Yahoo Finance v3: `new YahooFinance()` ile instantiate edilmeli (`lib/yahoo-finance.ts`)
- Komisyon: %0.2 alış, %0.2 satış
- Risk limitleri: İşlem başına max %1, günlük max %3 zarar
- Sanal bakiye: 100.000 TL başlangıç
